# Document API
External clients store document identifiers permanently. The API team proposes tenant-scoped identifiers; the import team proposes globally unique identifiers. Neither contract has been accepted. Separately, the service stores private documents, but the spec does not define whether only owners or also tenant administrators may read them. This access policy is independent of identifier scope. The import contract must specify how to resolve a historical identifier after a tenant move. The correct rule depends on which identifier scope is chosen. Error-message wording and request timeouts are configurable.
